# Jet Visualization

A Jupyter Notebook project for creating 3D visualizations of astrophysical jet magnetic-field structures from exact magnetohydrodynamical solutions.

## Overview

This project visualizes the magnetic-field geometry of an astrophysical jet using Python-based numerical and plotting tools. The workflow takes analytical or precomputed magnetohydrodynamical solution data and converts it into interpretable 3D visualizations.

The goal of the project is to make complex jet structures easier to inspect, compare, and communicate through clear scientific visualizations. It demonstrates Python-based post-processing, numerical data handling, and 3D plotting for astrophysical simulation and modelling outputs.

## Features

- 3D visualization of astrophysical jet magnetic-field structure
- Post-processing of magnetohydrodynamical solution data
- Numerical handling of spatial coordinates and field components
- Generation of diagnostic plots for scientific interpretation
- Jupyter Notebook workflow for interactive exploration
- Visualization-oriented code suitable for model inspection and presentation

## Tech Stack

- Python
- Jupyter Notebook
- NumPy
- Matplotlib
- 3D plotting tools from Matplotlib
- Scientific data visualization workflows
